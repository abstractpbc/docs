| Item | Value |
| --- | --- |
| Base URL | `https://api.abstract.inc` |
| Authentication | `Authorization: Bearer` with your API key, on every endpoint |
| Request and answer bodies | JSON, server-sent events when `stream` is `true`, or a file's bytes on the robot run file routes |

These pages describe each request. They do not send requests.
Run requests from your own machine, with the key in your program's environment:

```sh
curl -s https://api.abstract.inc/v1/models -H "Authorization: Bearer $(abstract token)"
```

Every error has the same body. See [Errors and limits](/errors).

## Robot models

| Endpoint | Serves |
| --- | --- |
| [`POST /v1/chat/completions`](/api-reference/robot-models/create-an-action-chunk) | One observation in, one action chunk out |

The WebSocket at `wss://api.abstract.inc/v1/responses` runs a whole episode on one socket.
OpenAPI does not describe it. See [Sessions over WebSocket](/robots/sessions).

## Robot runs

`/v1/robot/runs` stores your robot runs (episode logs, the Rerun recording with the camera video) under your account, and lists, downloads and deletes them.
Only the key's account reaches its runs.
An account stores up to 100 GiB of runs.

| Endpoint | Serves |
| --- | --- |
| [`GET /v1/robot/runs`](/api-reference/robot-runs/list-robot-runs) | List your completed runs |
| [`GET /v1/robot/runs/usage`](/api-reference/robot-runs/robot-runs-usage) | What your runs hold against the quota, and this month's metering |
| [`GET /v1/robot/runs/{robot}/{run}`](/api-reference/robot-runs/get-a-robot-run) | A completed run's manifest |
| [`DELETE /v1/robot/runs/{robot}/{run}`](/api-reference/robot-runs/delete-a-robot-run) | Delete every file of a run |
| [`POST /v1/robot/runs/{robot}/{run}/complete`](/api-reference/robot-runs/complete-a-robot-run) | Complete a run, so it is listed |
| [`PUT /v1/robot/runs/{robot}/{run}/files/{path}`](/api-reference/robot-runs/upload-a-run-file) | Upload a file of at most 64 MiB |
| [`GET /v1/robot/runs/{robot}/{run}/files/{path}`](/api-reference/robot-runs/download-a-run-file) | Download a file |
| [`DELETE /v1/robot/runs/{robot}/{run}/files/{path}`](/api-reference/robot-runs/delete-a-run-file) | Delete a file |
| [`GET /v1/robot/runs/{robot}/{run}/uploads/{path}`](/api-reference/robot-runs/resume-a-multipart-upload) | Resume a multipart upload |
| [`POST /v1/robot/runs/{robot}/{run}/uploads/{path}`](/api-reference/robot-runs/start-or-finish-a-multipart-upload) | Start or finish a multipart upload |
| [`PUT /v1/robot/runs/{robot}/{run}/uploads/{path}`](/api-reference/robot-runs/upload-a-part) | Upload one part |
| [`DELETE /v1/robot/runs/{robot}/{run}/uploads/{path}`](/api-reference/robot-runs/abort-a-multipart-upload) | Abort a multipart upload |
