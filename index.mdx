Abstract serves models over HTTPS at `https://api.abstract.inc/v1`.
One API key works for every model.
You send the key as a Bearer token.

## Robot action models

A robot model turns one observation into one chunk of actions.
An observation is the task as text, recent JPEG frames from each camera, and the robot's state.
A chunk is a list of action rows.
The robot executes the rows in order, at the model's control rate.

Call a robot model with `POST /v1/chat/completions`, one observation per request, or run a whole episode on a WebSocket at `/v1/responses`.

A robot model id has the form `origin/model:embodiment`.
`origin` names who made the weights.
`model` names the weights.
`embodiment` names the robot they drive.
Every base served robot model drives a bimanual YAM: two YAM arms, one scene camera, and one camera on each wrist.

<Warning>
Abstract returns numbers. It does not move your robot.
Check every action against your robot's limits before you execute it.
</Warning>
